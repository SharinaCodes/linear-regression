# Linear Regression
## Salary Prediction (Employee Salary Data)

This project analyzes an employee salary dataset using:

* **Descriptive statistics** (distributions, group comparisons, correlation)
* **Multiple linear regression** (ordinary least squares with backward stepwise elimination)

The goal is to determine which factors (gender, education level, years of experience, and job title) are significantly related to salary, and to quantify how much each one is associated with a change in salary.

The full write-up is in [`reports/REPORT.md`](reports/REPORT.md).

## How to Run

### Run the script

The script builds its paths from its own location, so it runs from either the project root or `src/`:

```bash
python src/salary_prediction.py
```

It prints each step to the console, saves the cleaned dataset to `data/cleaned_dataset.csv`, and saves all figures to `reports/figures/`.

Charts are saved without being displayed. To view them in windows as the script runs, set `SHOW_PLOTS = True` at the top of the script and close each window to continue.

### Run the notebook

Open and run:

* `notebooks/salary_prediction_project.ipynb`

## Data

## What the Script Does

`src/salary_prediction.py` runs the full analysis in order:

1. **Cleaning:** renames columns to lowercase with underscores, drops the 2 rows with missing values and the $350 salary record (a likely entry error), and lowercases job titles
2. **Exploration:** prints descriptive statistics and saves charts of salary by gender, education, experience, age, and job title keyword
3. **Correlation check:** confirms that age and years of experience are nearly collinear, so age is excluded from the model
4. **Encoding:** creates job title keyword flags (director, junior, senior, manager, analyst, engineer), an `is_male` flag, and education dummies with Bachelor's as the baseline
5. **Modeling:** fits an initial OLS model, then uses backward stepwise elimination to remove predictors with p > 0.05 one at a time
6. **Interpretation:** prints 95% confidence intervals and in-sample RMSE for the final model
7. **Assumption checks:** saves a residuals vs. fitted plot to check linearity, and prints the VIF for each predictor to check multicollinearity

The modeling uses `statsmodels`:

```python
import statsmodels.api as sm
from statsmodels.stats.outliers_influence import variance_inflation_factor
```
